# $bog_keyqr

Передача ключа между устройствами через QR: одно показывает ключ кодом, другое сканирует его камерой. Частый случай — перенести аккаунт Гипер Базы на телефон.

```tree
<= Transfer $bog_keyqr
	key <= key_text \
	found? <=> key_scanned? \
```

- `key` — что показать. Пустой — остаётся только сканер.
- `found?` — отсканированная строка. Проверять её на формат — дело приложения.
- `shown?` — показан ли ключ. По умолчанию скрыт: QR и кнопку копирования не видно, пока человек сам не попросит.

Сканер отдельно — `$bog_keyqr_scan` с тем же `found?`. Распознавание — [jsQR](https://github.com/cozmo/jsQR), камера — `$mol_video_camera`.
